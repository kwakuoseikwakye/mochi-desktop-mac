# Upstream assets

Source: https://github.com/miflow13/mochi-desktop

Commit: `9cdd1008c93d2d850277652e65087d2e1c8b066e`

The bundled PNGs and selected manifest entries are unmodified Mochi artwork.
The upstream MIT notice is bundled as `MOCHI-LICENSE.txt`.
Swift source is a new native implementation of the first companion milestone;
it does not claim full parity with the Linux runtime.

## Audio assets

Audio cues (`chirp.wav`, `eat.wav`, `spawn.wav`, `exit.wav`, `menu_open.wav`, `level_up.wav`, `rain.wav`) are imported from `miflow13/mochi-desktop` (`assets/audio/`) under the upstream MIT license and converted to 16-bit 44.1kHz PCM `.wav` for native macOS playback.
